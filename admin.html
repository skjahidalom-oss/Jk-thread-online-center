নোটিশ বোর্ড — Admin Panel

অ্যাডমিন লগইন

শুধু অনুমোদিত অ্যাডমিন ইমেইল ও পাসওয়ার্ড দিয়ে প্রবেশ করুন।

প্রথমে Supabase সেটআপ করে এই পেজের কনফিগারেশন বসাতে হবে।

নতুন নোটিশ প্রকাশ করুন

প্রকাশিত নোটিশ

সেটআপের আগে: এই Admin Panel তখনই কাজ করবে যখন Supabase প্রজেক্ট, notices টেবিল, অ্যাডমিন ইউজার ও RLS নিরাপত্তা নিয়ম তৈরি করে নিচের JavaScript-এ Project URL এবং anon/publishable key বসাবেন। কখনও service_role/secret key ওয়েবসাইটে বসাবেন না।

এই ফাইলের নাম admin.html। এটি আপনার ওয়েবসাইটের সঙ্গে একই GitHub repository-তে আপলোড করুন।
